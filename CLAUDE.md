# Soverter

Windows утилита на Go: ПКМ по видео → пресет ffmpeg → готовый файл рядом. Редактор пресетов (Gio, свой дизайн: графит + индиго, тёмная и светлая темы), окно прогресса с очередью, окно выбора пресета, меню Explorer (новое Windows 11 и классическое). Личный проект. Общение с владельцем и комментарии в коде: русский; интерфейс двуязычный (English по умолчанию, русский переключается в настройках).

## Команды

```powershell
go build -ldflags "-H=windowsgui" -o soverter.exe ./cmd/soverter   # GUI-сборка (без cgo, C-компилятор не нужен)
go vet ./... ; go test ./...                                          # весь прогон ~90 с (e2e гоняют реальный ffmpeg)
go test ./internal/cmdbuild ./internal/ffimport ./internal/gui ...    # быстрые пакеты
go run ./cmd/guidemo -shot <папка>                                    # рисует окна в PNG без экрана (headless Gio)
.\shellext\package.ps1                                                # собрать и подписать internal/shellext/assets/soverter.msix (нужны MinGW в PATH и Windows SDK; файл в git не хранится)
.\release.ps1 -Version 1.0.0                                           # релиз: пакет меню + exe + zip в dist\ (для загрузки в GitHub Releases)
```

Подкоманды exe: `edit` (по умолчанию), `run <id> <файл>...`, `pick`, `install`, `uninstall [--cert]`, `list`. GUI-сборка без консоли: вывод `list`/`install` виден только из обычного терминала (AttachConsole), из git-bash не виден.

После правок кода пересобирайте `soverter.exe` в корне репозитория: владелец запускает именно его (и меню Explorer ссылается на него), старый exe не подхватит изменения.

## Конфиг и данные

- `%APPDATA%\soverter\presets.toml` — пресеты и `[settings]`: `menu_mode`, `integration` (`classic` по умолчанию | `modern` = меню Windows 11, бета, нужен UAC), `auto_close`, `ffmpeg_path`, `language` (`en`|`ru`, пусто = en), `ui_scale` (проценты, пусто = 100), `menu_title` (пусто = по умолчанию, см. ниже).
- `%APPDATA%\soverter\menu.txt` — для DLL меню Windows 11 (`exe=`, `mode=`, `title=`, строки `id<TAB>name`), пересоздаётся при каждой установке меню.
- `%LOCALAPPDATA%\soverter\encoders.json` — кэш проверки энкодеров (7 дней). `%USERPROFILE%\.soverter\shellext` — файлы пакета меню.
- Стартовые пресеты (`preset.Defaults()`) создаются только при отсутствии файла; существующий конфиг владельца не обновляется. Суффиксы по умолчанию: `stretch-fhd`, `stretch-qhd`, `volume-6db`, `30fps`, `720p`, `h265`.

## Архитектура (`internal/`)

- `preset` — `presets.toml`, валидация, умолчания, `Settings` (`MenuName()`, `DefaultMenuTitle()`). Пресет либо **структурный** (`[preset.video]`/`[preset.audio]`), либо **старый/сырой** (только `vf`/`af`/`args`). Старые обязаны работать без изменений. У структурных `vf`/`af`/`args` — дополнительные фильтры/аргументы.
- `cmdbuild` — чистая сборка аргументов ffmpeg и валидация (`Args`, `Validate`, `CheckAvailability`). Всё про флаги энкодеров живёт здесь и покрыто тестами по семействам × режимам.
- `encoders` — доступность энкодеров: софт по `-encoders`, железо пробным кодированием; кэш в памяти и на диске. В кэше хранится непереведённая причина (`i18n.N`), перевод делается в `Report.Why`.
- `sizecalc` — битрейт по целевому размеру из ffprobe. `runner` — запуск ffmpeg, два прохода, прогресс, очередь. `ffimport` — парсер «Импорт из команды».
- `i18n` — `T`/`Err`/`N`, каталог `en.go`, `SystemLang()` (язык отображения Windows).
- `gui` — Gio (immediate mode, без WebView и cgo):
  - `theme/` — токены цветов (`DarkPalette`/`LightPalette`, тема по настройке Windows), шрифты: Roboto вшит (`eliasnaur.com/font`), Consolas (или Go Mono) для кода, Segoe Fluent Icons/MDL2 для иконок.
  - `kit.go` — сегментные переключатели `Seg`, поле `Field`, `Slider`, `Switch`, `Dialog`, `Section`, `Banner`; `widgets.go` — `Btn`, `Chip`, `Progress`.
  - `app.go` — окна (`Open`, процесс завершается при закрытии последнего), масштаб (`Scale`/`SetScale`, Ctrl+=, Ctrl+-, Ctrl+0), `Configure(settings)`.
  - `editor.go` — состояние и правила редактора (`editVideo` применяет перекрёстные правила), `editor_view.go` — отрисовка карточек, `preset_list.go` — список пресетов с drag-and-drop, `picker.go`, `progress.go`, `options.go`.
  - Форма конструктора выводится из пресета на каждом кадре; копии есть только у текстовых полей (`loadFields`/`pollFields`). Логику в отрисовку не класть.
  - Настройки языка и масштаба применяются и пишутся в `presets.toml` сразу (`persistUI`), не трогая несохранённые правки пресетов; то же делает «Готово» в «Параметры». «Сохранить» относится только к пресетам.
- `shellint` — классическое меню (реестр HKCU, за интерфейсом для моков). `shellext` — меню Windows 11: подписанный MSIX с C++ COM-библиотекой (`/shellext`), читает `menu.txt`; название корня по умолчанию выбирает сама по языку Windows. `ipc` — single-instance через loopback-порт 47613.
- `e2e` — тесты на реальном ffmpeg/NVENC; пропускаются, если ffmpeg нет.

## Правила и грабли

- Пресеты и аргументы ffmpeg передаются массивом в `exec.Command`, без shell. Пути с пробелами и кириллицей должны работать.
- Не писать в `presets.toml` пользователя при тестах и проверках: подменяйте `APPDATA` на временную папку. Повреждённый конфиг никогда не перезаписывается.
- Меню Windows 11: нельзя регистрировать пакет из папок внутри `AppData` (рабочая папка — `%USERPROFILE%\.soverter\shellext`). `SystemFileAssociations\video` в этой системе не работает, классическое меню регистрируется по расширениям. Пакет подписан самоподписанным `CN=soverter`; доверие ставится через UAC, из сессии Claude этого делать нельзя. Иконка: исходник `assets/icon.png`, производные (`soverter.ico`, `shellext/logo*.png`, `cmd/soverter/rsrc_windows_amd64.syso`) коммитятся и делаются `assets/icons.ps1`; меню берёт `soverter.exe,0`. `.msix`/`.cer` **не коммитятся** (в `.gitignore`), локально лежат после `package.ps1`; без них exe собирается, но `shellext.Available()` ложно, и меню ставится классическим. После правки `ctx.cpp` пересобрать пакет `package.ps1`; тесты пакета без `.msix` пропускаются.
- Не запускать `uninstall`/`install` на реальном реестре без нужды: это меню владельца.
- Поля TOML с нулём: числовые поля структурных пресетов помечены `omitempty,omitzero`, иначе пишутся `0.0`.
- AMF/QSV флаги собраны по документации, на железе не проверены (у владельца RTX 4070 SUPER).
- В Bash-инструменте длинные heredoc и `perl -0pi` с `\n` в строках ломаются (портят `\n`, пути, кавычки); для больших правок использовать Write/Edit, для сложных замен скрипт-файл. В PowerShell-инструменте нельзя называть функции как алиасы (`move`).

### Gio

- Клики по элементам списка обрабатывать **до** отрисовки (`listInput`), иначе строки, нарисованные раньше, показывают старое выделение до следующего кадра.
- В `Flex`-детях раскладывать только с `gtx` из замыкания, а не с внешним (внешний даёт ограничения всего окна: так кнопка в очереди перекрыла список). Для «выключенных» блоков брать `gtx.Disabled()` от внутреннего `gtx`.
- Обработчик перетаскивания (`gesture.Drag`) регистрировать **после** содержимого и под `pointer.PassOp`, иначе его перекрывает `Clickable`; рисовать перетаскиваемую строку через `op.Defer`. Синтетические события в тестах: `pointer.Move` с зажатой кнопкой (тип `Drag` роутер не принимает).
- Headless-рендер (`guidemo`, тесты) требует `layout.Context.Source` от `input.Router`, иначе все виджеты «выключены».
- Моноширинный шрифт сидит в строке выше середины: `monoNudge` сдвигает его вниз; поля ввода имеют фиксированную высоту и центрируются через `Stack`.
- Проводник: `explorer /select,"путь"` собирать через `SysProcAttr.CmdLine`, иначе Go ставит кавычки на весь аргумент и откроется папка по умолчанию.
- Для проверки UI в живом окне: запустить exe с временным `APPDATA`, управлять мышью через `mouse_event` (для drag нужны промежуточные относительные движения), снимать экран и смотреть.

## Локализация

Исходный язык кода русский: все видимые пользователю строки оборачиваются в `i18n.T("русский текст", args...)` (для пакетных переменных — `i18n.Err`, для хранимых/кэшируемых текстов — `i18n.N` и перевод позже через `T`), английские переводы лежат в `internal/i18n/en.go` (ключ = точный русский текст). Язык по умолчанию английский. `TestCatalogComplete` падает, если у литерала в `T`/`Err`/`N` нет перевода. Списки опций и константы-тексты строятся функциями (`codecOpts()`, `hwHint()`), а не пакетными переменными/константами, иначе перевод зафиксируется при инициализации. Тесты, сверяющие русский текст, закрепляют язык файлом `lang_test.go`. Для `fmt.Errorf`/`Sprintf` без аргументов использовать `"%s"` + `T(...)`, иначе `go vet` ругается.

Название пункта Explorer по умолчанию — в духе «Edit with Notepad++»: `Convert with Soverter` / `Обработать с помощью Soverter` (последнее при русском языке отображения Windows, независимо от языка программы); своё название — `menu_title`.

## Git

Репозиторий локальный (до первой публикации на GitHub), единственная ветка `main`; историю не переписывать. Коммит на логический этап, сообщения на английском, в конце строка `Co-Authored-By: Claude Sonnet 5.5 <noreply@anthropic.com>`. Бинарники не коммитятся: `soverter.exe`, `dist/`, `shellext/build/`, `internal/shellext/assets/soverter.msix` и `.cer` в `.gitignore` (собранное выкладывается в GitHub Releases; `AppxManifest.xml` и `logo.png` остаются исходниками). Рабочие файлы при `core.autocrlf` бывают с CRLF после переключения веток: многострочные `perl -0pi` тогда не срабатывают, правьте через Edit.

## Релиз и подпись

Меню Windows 11 в релизах подписано самоподписанным `CN=soverter` (доверие ставит пользователь через UAC), exe не подписан. Заявку в SignPath Foundation отклонили (мало охвата), `release.yml` удалён (остался в истории git, коммит до этого). Позже можно повторить заявку или взять сертификат CA. `shellext\package.ps1 -Unsigned -Publisher '<Subject>'` собирает неподписанный пакет без `.cer` (тогда `CertTrusted()` истинна, шага доверия и UAC нет, кнопка «Удалить сертификат из доверенных» скрыта, потому что `CertThumbprint()` пуст).
